Replication Project: 

Based off of: 
Infant Deaths After Texas’ 2021 Ban on Abortion in Early Pregnancy
Gemmill et al. 2024 
Published in JAMA Pediatrics

Files:
Scripts: 
repl_table_1 - script that cleans data and produces table 1 (summary stats)
repl_table_2 - script that takes cleaned data and produces main synthetic control results (Table 2 and 3 in the presentation)
repl_table_4 - script that tabulates summary statistics on cause of death (briefly mentioned in presentation, Table 4 in the paper)

Analysis Folder: 
Contains result of analysis and figures (in Excel)

Data Folder: 
Contains raw and cleaned data.
